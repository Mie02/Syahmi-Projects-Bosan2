⚙️ Installation & Setup Guide

Simple steps to install via ADB or directly on device.

adb-terminal — bash / pwsh

# 1. Connect phone via USB or Wireless Debugging and install directly:

adb install -r TurboBoost_Pro.apk

# 2. (Optional) Launch TurboBoost Pro immediately:

adb shell am start -n com.pixelbooster.app/.MainActivity

# 3. For automated debloating without computer cables:

• Install Shizuku from GitHub or Play Store.
• Enable Wireless Debugging in Android Developer Options.
• Pair and start Shizuku once, then launch TurboBoost Pro and authorize permission.
